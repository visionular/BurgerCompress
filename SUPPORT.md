# Burger Compress Support

Thank you for helping us improve Burger Compress. Please choose the right contact path so we can handle your request safely and efficiently.

## Product bugs and compatibility problems

For reproducible product problems, open a [GitHub issue](https://github.com/visionular/BurgerCompress/issues/new/choose).

Please include:

- Burger Compress version.
- Windows edition, version, and OS build.
- Whether the problem affects an image or a video, together with the input and output formats.
- Clear reproduction steps, expected result, and actual result.
- Relevant error text or sanitized logs.

Before uploading screenshots or logs, remove personal email addresses, access tokens, private file paths, filenames, and confidential media content. Do not upload private source media unless Visionular explicitly requests it and provides an approved transfer method.

## Account, privacy, and other requests

Email [info@visionular.com](mailto:info@visionular.com) for:

- Sign-in or account access problems.
- Account or personal-data requests.
- Questions about the Privacy Notice or Terms of Service.
- A problem that cannot be described safely in a public issue.

Security vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md), not through a public issue.

Official website: [burgercompress.visionular.net](https://burgercompress.visionular.net/)

# 汉堡压缩支持说明

感谢你帮助我们改进 Burger Compress（汉堡压缩）。请选择合适的联系渠道，以便我们安全、高效地处理问题。

## 产品故障与兼容性问题

对于能够复现的产品问题，请提交 [GitHub Issue](https://github.com/visionular/BurgerCompress/issues/new/choose)。

请提供：

- 汉堡压缩的版本号。
- Windows 版本、版本号和操作系统内部版本。
- 问题涉及图片还是视频，以及输入、输出格式。
- 清晰的复现步骤、预期结果和实际结果。
- 相关错误文字或已经脱敏的日志。

上传截图或日志前，请删除个人邮箱、访问令牌、私人文件路径、文件名和机密媒体内容。除非 Visionular 明确提出并提供经过认可的传输方式，否则请勿上传私人源媒体文件。

## 账户、隐私与其他请求

以下事项请发送邮件至 [info@visionular.com](mailto:info@visionular.com)：

- 登录或账户访问问题。
- 账户或个人信息相关请求。
- 对隐私说明或服务条款的疑问。
- 不适合在公开 Issue 中描述的问题。

安全漏洞请按照 [SECURITY.md](SECURITY.md) 私下报告，不要提交公开 Issue。

官方网站：[burgercompress.visionular.net](https://burgercompress.visionular.net/)
