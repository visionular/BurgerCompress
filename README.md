## Compress images and videos, your way

Burger Compress is a free desktop app for batch image and video compression and format conversion. Choose an official preset to get started, or adjust advanced settings and create personal templates for repeatable work.

Media processing runs on your computer. Your source media, thumbnails, file paths, processing history, and output files are not uploaded to Burger Compress servers.

### Free. Simple. Capable.

- **Free:** process local images and videos without signing in.
- **Simple:** add files, choose a preset, and start. Follow progress and results in one task queue.
- **Capable:** adjust quality, output formats, and supported advanced settings; save personal templates for recurring tasks.
- **Image size control:** use quality settings or a target file size for supported image workflows.
- **Batch workflow:** handle multiple files, review processing status, and open completed outputs.
- **Optional account features:** sync personal templates and send feedback from About. Media files are not part of template sync.
- **Two interface languages:** English and Simplified Chinese.

## Get started

1. **Add files.** Import one or more images or videos.
2. **Choose your settings.** Select an official preset and output format. Adjust quality or supported advanced options when needed.
3. **Start processing.** Choose the output location, run the task, and open the result. Source files are not overwritten by default.

## Supported input formats

| Type | Recognized source formats |
| --- | --- |
| Video | MP4, MKV, MOV, M4V, AVI, FLV, M2TS, MTS, TS, 3GP, 3G2 |
| Image | JPG, JPEG, WEBP, AVIF, HEIC, HEIF, PNG, APNG, BMP, TIF, TIFF, GIF |

This is an **input-format list**, not a promise that every format can be exported. Available outputs, codecs, filters, and hardware acceleration depend on the source media and the capabilities detected on your computer. Target file-size control is offered for supported image workflows.

## Privacy, accounts, and feedback

Local media processing does not require an account. Sign in to sync personal templates or send in-app feedback. Template sync does not include media files, thumbnails, local file paths, or processing history. One account supports up to five active devices.

### 图片与视频，轻松压缩，灵活调整

汉堡压缩是一款免费的桌面软件，支持批量压缩和转换图片、视频。选择官方模板即可开始；需要精细控制时，也可以调整高级参数，创建自己的模板。

媒体处理在你的电脑上完成。源文件、缩略图、文件路径、处理历史和输出文件不会上传到汉堡压缩服务器。

### 免费、简单、好用

- **免费：** 无需登录，即可处理本机的图片与视频。
- **简单：** 添加文件、选择模板、开始处理，进度与结果在任务队列中清晰展示。
- **好用：** 按需调整质量、输出格式和受支持的高级参数，把常用配置保存为个人模板。
- **图片体积控制：** 支持质量调节，并在受支持的图片流程中设置目标文件大小。
- **批量处理：** 一次处理多个文件，查看任务状态，直接打开处理结果。
- **可选账户功能：** 登录后同步个人模板，并在“关于”中发送反馈；模板同步不包含媒体文件。
- **中英双语：** 提供简体中文和英文界面。
