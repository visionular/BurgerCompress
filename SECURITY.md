# Security Policy

## Reporting a vulnerability

Please do not disclose suspected security vulnerabilities in a public GitHub issue.

Email [info@visionular.com](mailto:info@visionular.com) with the subject **Burger Compress Security Report**. Include, where possible:

- The affected Burger Compress version and Windows version.
- A concise description of the issue and its potential impact.
- Reproduction steps or a minimal proof of concept.
- Whether the issue has already been disclosed to anyone else.
- A safe way for us to contact you.

Do not send passwords, session tokens, private media, or unnecessary personal information. If supporting files contain sensitive information, ask us to arrange an appropriate transfer method first.

We will make a reasonable effort to acknowledge the report, investigate it, and coordinate remediation and disclosure. Submission of a report does not create an entitlement to payment or a bug bounty unless Visionular agrees to one in writing in advance.

## Supported versions

Security fixes are generally delivered in the latest publicly available version. Before reporting a problem, reproduce it with the latest version when it is safe to do so.

# 安全政策

## 报告安全漏洞

请勿在公开 GitHub Issue 中披露疑似安全漏洞。

请发送邮件至 [info@visionular.com](mailto:info@visionular.com)，邮件主题写明 **Burger Compress 安全漏洞报告**。在条件允许时，请提供：

- 受影响的汉堡压缩版本和 Windows 版本。
- 问题的简要说明及其潜在影响。
- 复现步骤或最小化验证样例。
- 是否已经向其他人披露该问题。
- 可以安全联系你的方式。

请勿发送密码、会话令牌、私人媒体或不必要的个人信息。如果辅助文件包含敏感信息，请先联系我们安排合适的传输方式。

我们会尽合理努力确认收到报告、开展调查，并协调修复与披露。除非 Visionular 事先书面同意，提交安全报告不代表自动获得报酬或漏洞奖励。

## 支持的版本

安全修复通常通过最新公开版本交付。在确保安全的前提下，请先使用最新版本复现问题，再提交报告。
