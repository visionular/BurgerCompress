## 1.0.1 · 2026-09-17

### English

- Adds signed-in feedback in **About**, with team replies sent to the verified account email.
- Refines About: a top-right close button, immediately saved update preferences, and a primary feedback button when a message is ready to send.
- Uses Alibaba Cloud OSS global acceleration for stable updates and downloads.
- The Windows x64 installer is digitally signed by **杭州微帧信息科技有限公司**, with a Certum OV certificate and an RFC 3161 timestamp.

- 稳定版更新与下载统一使用阿里云 OSS 全球加速地址。
- Windows x64 安装程序由**杭州微帧信息科技有限公司**使用 Certum OV 证书进行数字签名，并附 RFC 3161 时间戳。
